## 文件说明

| 文件                       | 用途                                                       |
| ------------------------ | -------------------------------------------------------- |
| `Microduck复刻站-单文件版.html` | 自包含单页整站，样式、脚本、数据全部内联，无任何外部依赖。上传后重命名为 `index.html` 即为站点入口 |
| `Microduck复刻站.zip`       | 完整多页面版本（四个 HTML 页面 + `assets/`），适合本地或电脑端部署               |
| `站点说明.md`                | 部署与维护手册，含 git 命令、Pages 设置、自定义域名                          |
| `assets/data.js`         | 完整多页版的数据文件，进度、配件、花费、软件、链接集中在这一个文件里                       |

如果你只上传了单文件版，改数据需要直接编辑 HTML 里的数据段；多页版则只改 `assets/data.js`。

## 部署到 GitHub Pages

单文件版的手机操作路径：

1. 打开 https://github.com/Joeliews/Microduck-Joe-lite
2. **Add file → Upload files**
3. 选中 `Microduck复刻站-单文件版.html`，把上传列表里的文件名改成 `index.html`
4. **Commit changes**
5. 进入 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`，目录选 `/(root)`，**Save**
6. 等 1–2 分钟，访问上面「在线访问」的地址

电脑端推送完整多页版：

```bash
git clone https://github.com/Joeliews/Microduck-Joe-lite.git
cd Microduck-Joe-lite
# 把站点文件拷贝进来，index.html 作为入口
git add .
git commit -m "发布 Microduck 复刻记录站"
git push origin main
```

## 配件与原版路线

原版 Microduck 的 15 个舵机是 **Dynamixel XL330-M288-T**（Dynamixel Protocol 2.0），单个价格偏高，占整机 BOM 四成以上。

我这台换成了 **飞特 1910** 作为国产替代，原因是原版电机买不到。它在配件表里单列为「国产替代」，与「原版同款」分开显示，并标注了选择原因。

**已知风险（待验证）**：XL330 走 Dynamixel Protocol 2.0，飞特的总线协议不同，官方 SDK 与强化学习策略的输出层大概率需要适配。等舵机到货完成归零与联调后，这一条会从「待验证」改成实测结论。
